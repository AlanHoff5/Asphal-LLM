# Glossário — Capítulo 6 e 7: Fine-Tuning

Termos na ordem em que aparecem nos capítulos. Os 14 termos obrigatórios do enunciado estão todos presentes.

---

**Fine-Tuning** — Ajuste fino: Continuação do treinamento de um modelo pré-treinado em dados menores e específicos de uma tarefa. Em vez de aprender do zero, o modelo parte de pesos já úteis e ajusta apenas o necessário para a nova tarefa.

**Pretrained Weights** — Pesos pré-treinados: Parâmetros de um modelo treinado em grande volume de dados (ex.: GPT-2 treinado em 1,5 B tokens da web). Carregá-los evita treinar do zero e transfere o conhecimento linguístico já adquirido.

**Transfer Learning** — Aprendizado por transferência: Estratégia de usar um modelo treinado em uma tarefa como ponto de partida para outra. No contexto de LLMs: pré-treinar em texto geral → fine-tuning em tarefa específica (classificação, instrução etc.).

**Classification Fine-Tuning** — Ajuste fino para classificação: Adaptação do GPT para prever uma classe (ex.: spam / não-spam) em vez de um token. Substitui a camada `lm_head` por uma `Linear(emb_dim, num_classes)` e treina com cross-entropy de classificação.

**Classification Head** — Cabeça de classificação: Camada linear adicionada ao topo do GPT para produzir logits de classe. Recebe a representação do último token e projeta para `num_classes` saídas. É a única camada treinada no fine-tuning mais conservador.

**Frozen Layers** — Camadas congeladas: Camadas cujos parâmetros não são atualizados durante o fine-tuning (`param.requires_grad = False`). Preservam o conhecimento pré-treinado e reduzem o custo computacional; apenas as camadas descongeladas aprendem a nova tarefa.

**Trainable Parameters** — Parâmetros treináveis: Parâmetros com `requires_grad = True`, que recebem gradientes e são atualizados pelo otimizador. No fine-tuning de classificação do livro: apenas a `classification_head` e os últimos blocos Transformer são treináveis.

**Supervised Fine-Tuning** — Ajuste fino supervisionado (SFT): Fine-tuning com dados rotulados — cada exemplo tem entrada e saída esperada conhecidas. Classificação com rótulos spam/ham é SFT; instruction fine-tuning com pares instrução/resposta também é SFT.

**Instruction Fine-Tuning** — Ajuste fino por instruções: Treinar o modelo para seguir comandos em linguagem natural (formato instrução → resposta). Usa datasets no estilo Alpaca (`instruction`, `input`, `output`) e mantém a cabeça de linguagem original (`lm_head`).

**Instruction Dataset** — Dataset de instruções: Conjunto de dados no formato `{instruction, input, output}`. Cada exemplo descreve uma tarefa, fornece contexto opcional e mostra a resposta esperada. Usado no instruction fine-tuning para ensinar o modelo a seguir comandos.

**Training Batch** — Lote de treinamento: Subconjunto de exemplos processados juntos em um passo do otimizador. No fine-tuning de classificação, cada lote contém pares `(texto, rótulo)`; no instruction fine-tuning, pares `(prompt formatado, resposta alvo)`.

**Classification Accuracy** — Acurácia de classificação: Fração de exemplos classificados corretamente. `acurácia = corretos / total`. É a métrica principal para avaliar o fine-tuning de classificação; complementada por precisão, revocação e F1 quando as classes são desbalanceadas.

**Evaluation Dataset** — Dataset de avaliação: Subconjunto dos dados **não usado no treino**, reservado para medir o desempenho real do modelo. Separar treino, validação e teste evita que a métrica reflita memorização em vez de generalização.

**Response Evaluation** — Avaliação de respostas: Medir a qualidade das respostas geradas no instruction fine-tuning. Pode ser feita por comparação com referência (BLEU, ROUGE), por julgamento humano ou por um LLM avaliador (LLM-as-a-judge). Mais subjetiva que a acurácia de classificação.

---

**LoRA** — Low-Rank Adaptation: Técnica de fine-tuning eficiente que congela os pesos originais e adiciona matrizes de baixo rank treináveis em paralelo (`W' = W + A·B`). Reduz drasticamente o número de parâmetros treináveis sem degradar muito o desempenho.

**Collate Function** — Função de agrupamento: Função passada ao `DataLoader` que recebe uma lista de exemplos e os organiza em tensores de lote. No instruction fine-tuning é essencial para alinhar sequências de tamanhos diferentes (padding ou truncagem).

**Padding Token** — Token de preenchimento: Token especial (`<|endoftext|>` no GPT-2, id 50256) usado para igualar o comprimento das sequências num lote. Os targets das posições de padding recebem `-100` para serem ignorados pela cross-entropy.
