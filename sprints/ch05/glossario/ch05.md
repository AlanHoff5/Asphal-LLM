# Glossário — Capítulo 5: Pré-treinamento

Termos na ordem em que aparecem no capítulo.

---

**Pretraining** — Pré-treinamento: Fase 1 do treinamento: o modelo lê texto bruto e aprende a prever o próximo token, sem rótulos. Transforma os pesos aleatórios do capítulo 4 em um modelo que escreve frases coerentes.

**Target** — Alvo: Token que realmente vem depois de cada posição — a "resposta certa". É a entrada deslocada uma posição para a direita (montado pelo Dataset do capítulo 2).

**Cross Entropy Loss** — Perda de Entropia Cruzada: Medida de erro do treino. Olha a probabilidade que o modelo deu ao token certo, tira o log, troca o sinal e faz a média. Quanto menor, melhor. Exemplo do livro: perda inicial ≈ 10,794.

**Log Probability** — Log-probabilidade: Logaritmo da probabilidade. Probabilidades pequenas (0,00001) viram números gerenciáveis (−11,5), tornando o cálculo numericamente estável. A cross-entropy é a média dos logs com sinal trocado.

**Perplexity** — Perplexidade: `exp(cross_entropy)`. Pode ser interpretada como "entre quantas palavras o modelo está em dúvida". Um chute uniforme no vocabulário de 50.257 tokens dá perplexidade ≈ 50.257 e perda ≈ 10,82.

**Training Set / Validation Set** — Conjunto de Treino / Validação: O texto é dividido antes de tokenizar. O modelo aprende só com o treino; a validação mede se ele generaliza. No livro: 90% treino, 10% validação de *The Verdict*.

**Training Loop** — Laço de Treinamento: Repetição que ajusta os pesos: zera gradientes → forward → perda → backward → optimizer.step(). Repete para cada lote de cada época.

**Epoch** — Época: Uma passada completa por todos os lotes de treino. Com 9 lotes e 10 épocas = 90 passos de atualização.

**Training Step / Iteration** — Passo de Treino: Uma atualização dos pesos a partir de um lote. O livro conta os passos em `global_step` e avalia a cada `eval_freq` passos.

**Tokens Seen** — Tokens Vistos: Total de tokens que passaram pelo modelo no treino. Permite comparar treinos com tamanhos de lote diferentes. Cresce `batch_size × context_length` por passo.

**Gradient** — Gradiente: Derivada da perda em relação a cada peso — diz se o peso deve subir ou descer. Calculado pelo `loss.backward()`.

**Backpropagation** — Retropropagação: Cálculo dos gradientes de trás para frente usando a regra da cadeia. Uma linha no PyTorch: `loss.backward()`.

**zero_grad / step**: `optimizer.zero_grad()` apaga gradientes do passo anterior (o PyTorch os acumula). `optimizer.step()` aplica a atualização. Ordem obrigatória: zero_grad → forward → loss → backward → step.

**Optimizer** — Otimizador: Algoritmo que usa os gradientes para atualizar os pesos. SGD usa um passo fixo; Adam/AdamW ajustam o passo por peso com base no histórico dos gradientes.

**AdamW**: Versão do Adam onde o weight decay é aplicado diretamente nos pesos, separado da atualização do gradiente. Usado no livro com `lr=0.0004` e `weight_decay=0.1`. Guarda duas médias por peso — o estado do otimizador ocupa ~2× o tamanho do modelo.

**Learning Rate** — Taxa de Aprendizado: Tamanho do passo de cada atualização. Alta demais → perda oscila ou explode; baixa demais → aprendizado lento. Valor do livro: `4e-4`.

**Weight Decay** — Decaimento de Pesos: Puxa os pesos em direção a zero a cada passo. Regularização que ajuda a evitar overfitting. Parte do AdamW.

**Hyperparameter** — Hiperparâmetro: Configuração escolhida antes do treino que o modelo não aprende: lr, épocas, batch_size, dropout, context_length, etc.

**Train Mode / Eval Mode** — Modo de Treino / Avaliação: `model.train()` liga dropout; `model.eval()` desliga. Em avaliação usa-se também `torch.no_grad()` para não calcular gradientes e economizar memória.

**Overfitting** — Sobreajuste: O modelo decora o treino em vez de aprender a língua. Visível quando a perda de treino cai mas a de validação para ou sobe. No livro: após 10 épocas, treino 0,391 vs. validação 6,452.

**Generalization** — Generalização: Capacidade de acertar em textos nunca vistos. Medida pela diferença entre perda de validação e treino. Quanto menor a diferença, melhor.

**Decoding Strategy** — Estratégia de Decodificação: Regra para escolher o próximo token a partir dos logits. Não muda os pesos — só a forma de gerar texto.

**Probabilistic Sampling** — Amostragem Probabilística: Sorteia o próximo token proporcionalmente às probabilidades do softmax, em vez de pegar sempre o maior (`argmax`). Gera texto variado.

**Temperature Scaling** — Escalonamento por Temperatura: Divide os logits por T antes do softmax. T < 1 → mais previsível; T > 1 → mais variado. T → 0 equivale à decodificação gulosa.

**Top-k Sampling** — Amostragem Top-k: Mantém só os k tokens com maiores logits; descarta o resto (logit = −∞). Evita escolhas absurdas mesmo com temperatura alta. Livro usa `top_k=25, T=1.4`.

**Random Seed** — Semente Aleatória: Número que fixa a sequência de valores aleatórios (pesos iniciais, dropout, sorteios). Permite reproduzir experimentos. Livro usa `torch.manual_seed(123)`.

**state_dict** — Dicionário de Estado: Dicionário PyTorch com nome → pesos de cada camada. Forma padrão de salvar e carregar um modelo. O otimizador também tem o seu.

**Checkpoint** — Ponto de Salvamento: Arquivo com pesos do modelo + estado do otimizador. Permite continuar treino ou usar o modelo sem retreinar. Exemplo: `torch.save({"model_state_dict": ..., "optimizer_state_dict": ...}, "checkpoint.pth")`.

**Pretrained Weights** — Pesos Pré-treinados: Pesos de um modelo já treinado pela OpenAI (GPT-2). Base para o fine-tuning dos capítulos 6 e 7. Requer `qkv_bias=True` e weight tying para compatibilidade.

**Learning Rate Warmup** — Aquecimento da Taxa de Aprendizado: Começa com lr pequeno e aumenta linearmente até o valor máximo nos primeiros passos. Estabiliza o início do treino quando os pesos ainda são aleatórios.

**Cosine Decay** — Decaimento Cossenoidal: Após o warmup, lr decresce seguindo meia onda de cosseno até um mínimo. Passos grandes no início, ajustes finos no fim.

**Gradient Clipping** — Corte de Gradiente: Se a norma do gradiente exceder `max_norm`, escala todos os gradientes proporcionalmente. Evita "explosão de gradiente". PyTorch: `clip_grad_norm_(model.parameters(), max_norm=1.0)`.
