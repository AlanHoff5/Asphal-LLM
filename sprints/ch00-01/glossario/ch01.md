Deep Learning — Aprendizado Profundo: Parte do Machine Learning que usa redes neurais com várias camadas. A rede descobre sozinha os padrões nos dados, sem que alguém precise listar as regras à mão. É a base de todo LLM, na sequência IA → Machine Learning → Deep Learning → LLM. Exemplo: um filtro de spam comum depende de uma lista de palavras suspeitas; uma rede profunda aprende quais são olhando os e-mails.

Large Language Model (LLM) — Modelo de Linguagem de Grande Escala: Rede neural treinada com muito texto para entender e gerar linguagem. "Grande" se refere ao número de parâmetros e à quantidade de texto usada no treino. É o que o projeto constrói, e todos os outros termos deste glossário explicam uma parte dele. Exemplo: o GPT-3 tem 175 bilhões de parâmetros.

Parameter / Weight — Parâmetro / Peso: Número ajustável dentro da rede, que muda durante o treino. É onde fica guardado o que o modelo aprendeu, e a quantidade de parâmetros indica o tamanho do modelo. Exemplo: o GPT-3 tem 175 bilhões de parâmetros.

Token — mantém-se o termo em inglês: Pedaço de texto que o modelo lê, como uma palavra, parte de uma palavra ou um sinal de pontuação. Tudo no modelo funciona token a token: ele lê tokens e prevê o próximo token. Exemplo: o GPT-3 foi treinado com cerca de 300 bilhões de tokens.

Embedding — Vetor de Representação: Lista de números que representa um token. Transforma o texto em algo que a rede consegue calcular, e tokens com sentido parecido ficam com vetores parecidos. É a porta de entrada do Transformer. Exemplo: no GPT-2 pequeno, cada token vira uma lista de 768 números.

Transformer — mantém-se o termo em inglês: Arquitetura de rede neural criada em 2017 no artigo "Attention Is All You Need", inicialmente para tradução. Tem duas partes, o Encoder e o Decoder, ligadas pela Attention. Quase todos os LLMs atuais usam essa arquitetura. Observação do livro: nem todo Transformer é um LLM, e nem todo LLM é um Transformer.

Encoder — Codificador: Parte do Transformer que lê o texto de entrada e o transforma em vetores com o contexto da frase. O BERT usa só essa parte; o GPT não a usa. Exemplo: numa tradução, o encoder lê a frase em português.

Decoder — Decodificador: Parte do Transformer que gera o texto de saída, um token por vez. É a única parte que o GPT mantém. Exemplo: numa tradução para o alemão, depois de "Das ist ein" o decoder gera "Beispiel".

Decoder-Only Architecture — Arquitetura Somente-Decodificador: Versão do Transformer que usa só o Decoder. É mais simples e funciona bem para gerar texto. É a arquitetura da família GPT e a que o projeto implementa no Capítulo 4.

Attention / Self-Attention — Mecanismo de Atenção / Auto-Atenção: Parte do modelo que faz cada token "olhar" para os outros tokens da frase e decidir quais são mais importantes para ele. É o que permite ao modelo entender o contexto, mesmo entre palavras distantes. É o assunto da Sprint 3. Exemplo: em "o animal não atravessou a rua porque ela era larga", a atenção liga "ela" a "rua".

GPT (Generative Pretrained Transformer) — Transformer Generativo Pré-Treinado: Família de modelos da OpenAI que usa só o Decoder e é feita para gerar texto: completar frases, traduzir, resumir, escrever código. Passa por pré-treinamento e depois por fine-tuning. É o modelo que o projeto constrói. Exemplo: o GPT-3 tem 96 camadas Transformer; o Transformer original tinha 6.

BERT (Bidirectional Encoder Representations from Transformers) — Representações Bidirecionais de Codificadores a partir de Transformers: Família de modelos que usa só o Encoder e é treinada para preencher palavras escondidas. Como lê a frase inteira, nos dois sentidos, é boa para classificar textos. É o oposto do GPT. Exemplo: o X (antigo Twitter) usa BERT para detectar conteúdo tóxico.

Raw Text — Texto Bruto: Texto sem rótulos, ou seja, sem ninguém ter marcado respostas nele. Pode ter passado por uma limpeza simples, como tirar formatação. É a matéria-prima do pré-treinamento.

Self-Supervised Learning — Aprendizado Auto-Supervisionado: Forma de treino em que as respostas vêm do próprio texto, sem marcação humana. Como a próxima palavra já está no texto, ela serve de gabarito. É o que permite treinar com volumes enormes de texto. Diferente do Classification Fine-Tuning, que precisa de rótulos feitos por pessoas.

Next-Word Prediction — Predição da Próxima Palavra: Tarefa usada para treinar o GPT: dado um trecho de texto, prever a próxima palavra. É dela que vem toda a capacidade de linguagem do modelo. Exemplo: depois de "O céu está", o modelo deve prever algo como "azul".

Masked Word Prediction — Predição de Palavra Mascarada: Tarefa usada para treinar o BERT: algumas palavras da frase são escondidas e o modelo precisa adivinhá-las. É o contraponto da Next-Word Prediction do GPT. Exemplo: "Este é um ___ de como eu ___ ser breve".

Autoregressive Model — Modelo Autoregressivo: Modelo que usa as próprias respostas anteriores para gerar a próxima. É assim que o GPT escreve: gera uma palavra, coloca no texto e usa tudo para gerar a seguinte. Exemplo: gera "Das", depois "ist", depois "ein".

Pretraining — Pré-Treinamento: Primeira fase do treino, feita com muito texto bruto e a tarefa de prever a próxima palavra. O modelo aprende a linguagem em geral e vira um Foundation Model. É a fase mais cara. Exemplo: estima-se que o pré-treinamento do GPT-3 custou US$ 4,6 milhões.

Foundation Model / Base Model — Modelo de Fundação / Modelo Base: O modelo que sai do pré-treinamento. Sabe completar textos, mas ainda não segue instruções direito. Serve de ponto de partida para o fine-tuning. Exemplo: o GPT-3 antes de virar o ChatGPT.

Fine-Tuning — Ajuste Fino: Segunda fase do treino, com poucos dados e rotulados, para especializar o modelo em uma tarefa. Aproveita o que o modelo já aprendeu, por isso é bem mais barato que o pré-treinamento. Tem dois tipos principais: Instruction Fine-Tuning e Classification Fine-Tuning.

Instruction Fine-Tuning — Ajuste Fino por Instruções: Fine-tuning com pares de pedido e resposta. Faz o modelo deixar de só completar texto e passar a obedecer comandos. Foi assim que o ChatGPT surgiu a partir do GPT-3. Exemplo: "Traduza para o alemão: bom dia" → "guten Morgen".

Classification Fine-Tuning — Ajuste Fino para Classificação: Fine-tuning com textos marcados por categoria. A camada final do modelo é trocada para escolher entre essas categorias. É o assunto do Capítulo 6. Exemplo: "Você ganhou um prêmio, clique aqui" → spam.

Downstream Task — Tarefa Subsequente: A tarefa específica para a qual o modelo é ajustado depois do pré-treinamento. A ordem é sempre: Pretraining → Foundation Model → Fine-Tuning → Downstream Task. Exemplos: classificar spam, responder perguntas médicas, resumir documentos.

Emergent Behavior — Comportamento Emergente: Habilidade que o modelo mostra sem ter sido treinado para ela. Aparece por causa do tamanho do modelo e da variedade de textos do treino. Exemplo: o GPT consegue traduzir, mesmo tendo sido treinado só para prever a próxima palavra.

Zero-Shot Learning — Aprendizado sem Exemplos: Fazer uma tarefa nova só com a instrução, sem nenhum exemplo. É um tipo de comportamento emergente. Exemplo: pedir "Traduza para o alemão: breakfast =>" sem mostrar nada antes.

Few-Shot Learning — Aprendizado com Poucos Exemplos: Fazer uma tarefa a partir de alguns exemplos colocados no próprio pedido, sem treinar o modelo de novo. O Foundation Model já consegue fazer isso. Exemplo: mostrar "gaot => goat" e "sheo => shoe" e depois perguntar "pohne =>".

PyTorch — mantém-se o termo em inglês: Biblioteca de Python para Deep Learning, usada pelo livro e pelo projeto. Fornece os tensores, o cálculo automático de gradientes, as camadas prontas e o uso da placa de vídeo. Não é um conceito teórico, é a ferramenta com que todo o modelo é escrito. Exemplo: torch.nn.Linear(768, 768) cria uma camada da rede.
